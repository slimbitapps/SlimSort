# SlimBit Apps – Startseite

Diese Dateien gehören ins Repository **`slimbitapps.github.io`**.
Dann ist die Seite unter **https://slimbitapps.github.io** erreichbar.

- `index.html` – Startseite. Oben im Skript: YouTube-Link, E-Mail und die Liste der Apps (`APPS`).
- `impressum.html`, `datenschutz.html` – gelb markierte Stellen durch deine Daten ersetzen.
- `logo.svg` / `logo.png` – Logo. `youtube-avatar.png` – Profilbild für YouTube & Co.
