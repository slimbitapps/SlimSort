## YouTube Shorts
**Titel** (max. 100 Zeichen, die ersten Wörter zählen):
```
I sorted 2,000 vacation photos in 10 minutes 😳 #shorts
```
**Beschreibung:**
```
One key per folder – that's it. SlimSort is a free photo sorter for Windows & Mac.
⬇️ Free download: https://slimbitapps.github.io/SlimSort/

#photography #organization #freesoftware
```
**Beim Hochladen:**
- **Ähnliches Video:** das Intro-Video auswählen (so führt der Short zum langen Video)
- Zielgruppe: nicht speziell für Kinder
- Untertitel: **nicht** zusätzlich einschalten – sie sind schon eingebrannt
- Musik: in der YouTube-App beim Short unter „Sound“ ein Lied leise dazu (Lautstärke Musik ~10 %, Originalton 100 %)

**Angepinnter Kommentar:**
```
Free download link is in my profile 👆 What would you sort first – vacation, phone backup or old hard drive?
```

## TikTok

```

```
- Link in der Bio: `https://slimbitapps.github.io/SlimSort/` (Profil bearbeiten → Website; je nach Konto erst ab einer bestimmten Follower-Zahl möglich – sonst den Link in die Bio schreiben)
- Beim Posten einen **Trend-Sound** sehr leise darunterlegen (in TikTok: Sounds → Lautstärke „Hinzugefügter Sound“ auf ~10 %)
